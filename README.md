# 🚆 Raily

**Raily** یک اپلیکیشن دسکتاپ برای مدیریت کارهای روزانه و نظم دادن به برنامه‌های شخصیه که با استفاده از Electron و React توسعه داده می‌شه.

هدف Raily اینه که کمک کنه کارها، هدف‌ها و فعالیت‌های روزانه‌ات رو در یک محیط ساده و یکپارچه مدیریت کنی.

## ✨ امکانات

- 📝 مدیریت کارها و وظایف روزانه
- 🎯 ثبت و پیگیری هدف‌های شخصی
- 📅 مدیریت فعالیت‌ها و برنامه‌های روزانه
- 🌙 ثبت و بررسی اطلاعات مربوط به خواب
- 🧠 ثبت یادداشت‌ها و وضعیت ذهنی
- ⏰ پشتیبانی از ساعت سیستم و قابلیت استفاده از زمان سرور
- 📊 مشاهده گزارش‌ها و بررسی روند فعالیت‌ها
- ⚙️ تنظیمات قابل شخصی‌سازی

> امکانات و جزئیات نهایی ممکنه با پیشرفت توسعه پروژه تغییر کنن.

## 🛠️ فناوری‌های استفاده‌شده

- **Electron** برای اجرای برنامه روی دسکتاپ
- **React** برای ساخت رابط کاربری
- **TypeScript** برای توسعه ساختاریافته‌تر
- **Node.js** برای بخش‌های سمت برنامه دسکتاپ

## 💻 سیستم‌عامل‌های هدف

- Windows
- Linux

پشتیبانی از هر سیستم‌عامل به آماده بودن و آزمایش خروجی مربوط به همان سیستم‌عامل بستگی داره.

## 🚀 اجرای پروژه در محیط توسعه

ابتدا Node.js و npm رو نصب کن. سپس مخزن رو دریافت کن:

```bash
git clone https://github.com/parham0541/Raily.git
cd Raily
```

وابستگی‌ها رو نصب کن:

```bash
npm install
```

برای اجرای پروژه، دستور متناسب با اسکریپت‌های تعریف‌شده در `package.json` رو اجرا کن.

## 📦 ساخت خروجی

خروجی نهایی برنامه به ابزارهای ساخت و تنظیمات پروژه بستگی داره. پس از تنظیم فرایند Build می‌شه نسخه‌های قابل نصب برای سیستم‌عامل‌های هدف تولید کرد.
